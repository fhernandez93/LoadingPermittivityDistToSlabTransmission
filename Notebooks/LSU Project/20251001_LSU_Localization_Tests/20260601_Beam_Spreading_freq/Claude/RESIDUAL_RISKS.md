# Residual risks — what cannot be resolved from the existing data, and the cheapest test for each

Each item is a risk that survives the audit because the current two HDF5 files cannot settle it. The
"cheapest test" is the minimal action that would resolve it; none is launched here (no cloud runs).

| # | Residual risk | Why unresolved from current data | Cheapest resolving test |
|---|---|---|---|
| R1 | **Transverse tiling forbids > 1-tile localization.** The base cell is tiled 12× (period = L = 5.58 a), so transverse transport is Bloch-periodic and σ²(t) is only a transport observable for σ² ≲ 30 a². No localization length can be claimed at fixed L in this geometry. | The tiling is intrinsic to how the sample was built; no post-processing removes it. | One FDTD run with a **larger, non-tiled** transverse domain (a single realization ≥ 20 L wide, as in Yamilov 2023 / Haberko 2020), or explicitly verify the intended structure is genuinely aperiodic at 12× scale. Until then, cap all σ² fits at ~1 tile. |
| R2 | **No thickness scaling** — the decisive localization discriminator (σ²_∞ ∝ 2Lξ vs (3/8)L² vs artifact) needs ≥ 2 thicknesses. | Single L = 14.3 µm dataset. | Two more runs at L = 2× and 3× the base cell (the structure generator already supports multiplicate factors); compare σ²_∞(L) slope. This is the single highest-value follow-up. |
| R3 | **g(ν) values are Born/RDG-unreliable** (contrast \|m−1\| = 1.9 ≫ 0.1), so ℓ*(ν) = ℓ_s/(1−g) is only indicative even after the ordering fix (A2). | The g file was produced by a single-scattering model invalid at this contrast; the generator itself warns. | Regenerate g(ν) with the corrected multiple-scattering toolkit (`20260608_Get_g_factor*`, currently `_do_not_use`) for n = 2.90/ff = 0.2237, or extract ℓ* directly from the CW depth profile I(z) (Yamilov method) if an internal-field monitor is ever run. |
| R4 | **Absolute cross-run power mismatch (factor 1.4–3.3, smooth in ν).** Prevents any absolute transmission/absorption comparison between the periodic and absorbing files. | Cause is entangled: different meshes (different staircased transmission), lateral absorber loss, and possibly an unrecorded launch difference. | Compare **time-gated early transmission** (t < 2 ps, before lateral losses act) between the two files at nearest-bin ν; or a small local λ0/N convergence run to isolate the mesh contribution. |
| R5 | **Finite uniform PlaneWave patch is a frequency-dependent source** (aperture 0.31–1.22 λ across the band), so part of the ν-dependence of spreading is source, not transport. | Cannot separate source ν-dependence from transport in a single source geometry. | One run with a **GaussianBeam** (or an embedded interior source at depth z′ ≈ ℓ*) reproducing the same σ²(t) would confirm the transport is source-independent. |
| R6 | **High-ν numerical dispersion.** Mesh falls to ≈ 9.4 points/wavelength at ν ≳ 1 and the two runs discretize the same ν differently. | AutoGrid was anchored at the pulse centre; the λ_min refinement is dead code in the wrapper. | A λ0/20 → λ0/40 convergence scan at one high-ν point (Yamilov's resolution-robustness protocol); or simply flag ν ≳ 1 as resolution-limited. |
| R7 | **Reconstruction floor vs true late-time signal.** The ~10⁻⁵ floor is mostly band-truncation leakage (the periodic run, which cannot alias, shows it too), so late-time "saturation" near the floor is untrustworthy. | Only 1700 bins over a finite band; the true impulse response is longer than the record. | Longer FDTD run time (until the shutoff 1e-20 is actually reached) and/or apodization of the frequency-domain monitor; both require a re-run. |
| R8 | **Surface/interface waves at the exit-face monitor.** Source illuminates the front face from outside and the monitor sits exactly on the exit face — the configuration Goïcoechea 2026 show maximizes coherent, non-subtractable interfacial-wave contamination. | A single exit-face monitor cannot separate interface-guided from bulk-transmitted intensity. | One run with an **interior** detection plane (z = L/2 − ~1.5 a) or a (y,z) cross-section monitor to inspect interface-guided intensity. |
| R9 | **Gap-edge provenance** ([0.432, 0.460] from `gap_data.hdf5["Circular"]["0.22"]`, ff 0.22 vs 0.2237). Empirically the measured S(f) dip [0.427, 0.463] corroborates it to < 2e-5 in ν, so this is low-risk, but the MPB dimensionality/units were not re-derived. | The MPB calculation is external to this folder. | Re-run the MPB band structure for the exact structure, or accept the empirical dip position (already cross-checked in both datasets). |

**Prioritization.** R1 and R2 are the load-bearing structural limits — until a wider, thicker,
non-tiled run exists, the strongest honest claim is "consistent with transverse confinement near the
gap, localization not proven." R3–R9 affect quantitative accuracy but not that top-line conclusion.
